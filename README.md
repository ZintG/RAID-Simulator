Simulador de arreglos RAID. 

Objetivo: simular el funcionamiento de como funcionan las versiones de RAID 0, RAID 1, RAID 5 y RAID 10 en ejecucion.

El programa es bastante simple en funcionamiento e implementacion. Su mayor fuerte es la capacidad de ver a un alto nivel como funcionan conceptualmente los arreglos RAID a la hora de escribir, leer o recuperar informacion, para esto el programa permite que el usuario pueda abrir los archivos .bin que se crean para cada disco configurado en tiempo de ejecucion.

Se incluye un makefile para compilacion y ejecucion del programa.

RAID array simulator. 

Objective: simulate the operation of how the versions of RAID 0, RAID 1, RAID 5 and RAID 10 work in execution.

The program is quite simple in operation and implementation. Its greatest strength is the ability to see at a high level how RAID arrays work conceptually when writing, reading or recovering information. For this, the program allows the user to open the .bin files that are created for each disk configured at run time.

A makefile is included for compiling and executing the program.
